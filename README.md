# Portfólio Pessoal — Giovanni Feliciano

Portfólio pessoal desenvolvido para apresentar minha trajetória, habilidades e projetos na área de tecnologia.

## ✨ Recursos

- Página inicial moderna e responsiva
- Seção Sobre mim
- Habilidades e tecnologias
- Projetos em destaque
- Links para GitHub e contato por e-mail
- Modo claro/escuro com preferência salva
- Navegação responsiva para celular
- Animações de entrada e scroll suave
- SEO básico e HTML semântico

## 🚀 Como executar

Não há dependências obrigatórias. Abra o `index.html` no navegador ou publique os arquivos em qualquer hospedagem estática.

## 📁 Estrutura

- `index.html` — estrutura e conteúdo
- `styles.css` — visual, responsividade e temas
- `script.js` — menu, tema, animações e ano do rodapé
